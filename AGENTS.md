# AGENTS.md

## Express mode

.express enters a modal fast iteration mode and stays in it until .express off or .express exit is entered.

In express mode, your goal is to implement the prompt as quickly as possible, so skip tests, both writing and running them.  Do not lint or tscheck.

Do preserve all other prior assumptions when refactoring.
